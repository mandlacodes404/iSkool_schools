## PATH 1: LEARNING QUIZ (Formative - Just Practice)

```
DAILY WARM-UP OR PRACTICE QUIZ
├─ Duration: 5-15 minutes
├─ Attempt Limit: UNLIMITED
│  └─ Why: Students can retry to learn
├─ Layout: SINGLE PAGE
│  └─ Why: Less stressful, allows review
├─ Shuffle: NO
│  └─ Why: Order helps learning
├─ Publish Marks: YES
│  └─ Why: Immediate feedback helps
├─ Status: OPEN
│  └─ Why: Always available for practice
├─ Question Types:
│  ├─ Mostly MCQ (easy to understand)
│  └─ Some FITB (vocabulary building)
└─ Summative: NO (doesn't count toward grade)

RESULT FOR STUDENTS:
- Low pressure, judgment-free zone
- Can retake as many times as they want
- Immediate feedback on answers
- Helps identify weak areas before real test
```

---

## PATH 2: REVIEW QUIZ (Summative Study Guide - Before the Test)

```
CHAPTER REVIEW OR PRACTICE EXAM
├─ Duration: 20-45 minutes
├─ Attempt Limit: 2-3 times
│  └─ Why: Can learn from mistakes, improve
├─ Layout: SINGLE PAGE
│  └─ Why: Can review answers before submitting
├─ Shuffle: YES
│  └─ Why: Start preparing for randomized exam
├─ Publish Marks: YES (if no open-ended) or NO (if open-ended)
│  └─ Why: Helps students see what they missed
├─ Status: SCHEDULED or OPEN
│  └─ Why: Available for practice period
├─ Question Types:
│  ├─ 70% MCQ (most common on real test)
│  ├─ 20% FITB (vocabulary/facts)
│  └─ 10% Open-ended (deeper thinking)
└─ Summative: NO (doesn't count toward final grade)
               BUT tests same content as real test

RESULT FOR STUDENTS:
- Realistic practice with actual exam format
- Can learn from mistakes on similar questions
- See which topics need more study
- Building confidence for real exam
- Hopefully score improves from attempt 1→2→3
```

## PART 5: PUBLISH MARKS DECISION

```
CAN YOU AUTO-PUBLISH MARKS?

                ┌─ Check your questions
                │
          "Do you have OPEN-ENDED questions?"
                │
          ┌─────┴─────┐
          ↓           ↓
         YES          NO
    (Essays,      (MCQ + FITB
     Analysis)     only)
          ↓           ↓
        CAN'T        CAN
    AUTO-PUBLISH  AUTO-PUBLISH
        │            │
        │            ├─ Yes: Publish marks
        │            │ Students see grades
        │            │ Immediately after submit
        │            │
        │            └─ No: Hide marks
        │              You publish manually later
        │              After you review/grade
        │
        └─ You MUST:
          1) Grade all open responses first
          2) Then publish marks manually
          3) System prevents auto-publish
             when open-ended exist

FLOW FOR OPEN-ENDED QUIZZES:
Day 1: Students submit → Scores auto-calculated (MCQ/FITB)
       → Open-ended scores PENDING
Day 2-3: You grade all open responses
Day 4: You publish marks → Students see full scores
       (MCQ + Manual grades + Overall)
```

```
│ Chapter 5 Test               10%    │
│ ─────────────────────────────────── │
│ Midterm Exam                 20%    │
│ ─────────────────────────────────── │
│ Final Project                20%    │
│ Final Exam                   20%    │
├─────────────────────────────────────┤
│ TOTAL:                      100%    │
└─────────────────────────────────────┘

TYPICAL WEIGHTS BY IMPORTANCE:
├─ Quick check (Chapter quiz):    5-10%
├─ Medium assessment:             10-15%
├─ Major test/project:            15-20%

      Small quizzes = small weight
      Should total ~100%
```

### EXAMPLE 3: Unit Test (High-Stakes)

```
DECISION FLOW:
Path 3 (Grading) → HIGH-STAKES
├─ Duration: 60 min
├─ Attempt: 1
├─ Layout: Multi-Page (LINEAR) ← Prevents going back
├─ Shuffle: YES
├─ Publish: YES
├─ Question Type: 30 MCQ + 10 FITB (no open-ended)
├─ Summative: YES
├─ Weight: 15%
└─ Status: Scheduled (specific date 9:00 AM)

→ After submit: Auto-graded → Marks published instantly
```

### EXAMPLE 4: Final Exam (Comprehensive)

```
DECISION FLOW:
Path 3 (Grading) → MAXIMUM STAKES
├─ Duration: 120 min
├─ Attempt: 1
├─ Layout: Multi-Page (LINEAR) ← Professional format
├─ Shuffle: YES ← Different test for each student
├─ Publish: YES (only MCQ/FITB, no open-ended)
├─ Question Type: 50 MCQ + 10 FITB
├─ Summative: YES
├─ Weight: 25% ← Significant impact on final grade
└─ Status: Scheduled (June 10, 2:00 PM sharp)

CREATED QUIZ → Posted May 20 → Students study from May 20-June 10
→ June 10: Everyone starts at 2:00 PM simultaneously
→ 2 hours time limit per student
→ After submit: Auto-graded → Marks published
→ Score affects final transcript
```

## FINAL CHECKLIST BEFORE CLICKING CREATE

```
☐ Purpose: Formative? Summative? (Low/Med/High stakes?)
☐ Duration: ___ minutes (Is it realistic?)
☐ Class: Correct class selected?
☐ Attempt Limit: 1? Multiple? Unlimited?
☐ Layout: Single Page? Multi-Page (Linear)?
☐ Shuffle: YES? NO?
☐ Start Time: When should it become available?
☐ Status: Open? Scheduled? Closed?
☐ Question Types: MCQ? FITB? Open-ended?
  ├─ If Open-ended: Set Publish Marks = NO (you'll grade manually)
  └─ If MCQ/FITB only: Can set Publish Marks = YES
☐ Summative: NO (practice)? YES (counts toward grade)?
  ├─ If YES: Weight % entered? (e.g., 15%)
  └─ If NO: Done
☐ Total Points: Do they make sense?
  └─ (Usually 20-100 points for a quiz)

IF ALL ☑️ = Ready to CREATE
```
