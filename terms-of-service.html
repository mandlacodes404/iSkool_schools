Description of Service

iSkool is a cloud-based Learning Management System designed for South African high schools. The platform provides tools for running quizzes and assignments, tracking learner performance, managing the CAPS syllabus, communicating with learners and parents, and generating academic reports.

iSkool is provided as a Software-as-a-Service (SaaS) product and is accessed via a web browser without the need to install any software.
