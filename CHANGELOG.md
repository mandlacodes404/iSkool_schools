## [1.2.1] - 2026-08-15
### Added
- Teacher Announcements (Desktop): Added a Delete action to the detail panel, with a confirmation modal matching the existing Resources delete pattern; school-wide announcements posted by admin are not deletable from here. Backed by a new endpoint that checks ownership before deleting (`announcements.js`, `announcements.css`, `delete_announcement.php`).
- Teacher Assignments (Desktop): Added a Delete action alongside "Download All" in the detail panel, with the same confirmation modal pattern. The new endpoint blocks the delete and tells the teacher how many learners have already submitted, rather than silently removing their work; only deletes the assignment's attachment and row once there are zero submissions (`assignments.js`, `assignments.css`, `delete_assignment.php`).
- Teacher Syllabus (Desktop): Added a Delete action next to the term badge in the detail panel, with the same confirmation modal pattern. The new endpoint performs a straightforward ownership-checked delete (`sbo.js`, `sbo.css`, `delete_sbo.php`).
- Teacher Evaluations (Desktop): Added a Delete action to the detail panel, with the same confirmation modal pattern. The new endpoint blocks the delete and tells the teacher how many learners have already responded, protecting anonymous response data; only deletes the evaluation's statements and row once there are zero responses. The evaluation's `id` is now included in `get_evaluations.php`'s response, which previously omitted it (`evaluations.js`, `evaluations.css`, `delete_evaluation.php`, `get_evaluations.php`).
