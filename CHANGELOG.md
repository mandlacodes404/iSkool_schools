## [v1.2.4] - 2026-09-07
### Added
- Learner Quiz & Assignments (Mobile): Added a proper empty state for both pages — when a teacher hasn't posted anything yet, the list now shows a centred icon (matching each page's own accent colour) with a short heading and explanation, instead of a bare unstyled line of text. The search bar stays visible and tappable in this state (`quiz.js`, `assignments.js`).
- Learner Quiz & Assignments (Mobile): Searching now shows a "No matches for '...'" state with a search icon when a filter matches nothing, instead of the list silently going blank with no explanation or way to tell it's empty rather than broken (`quiz.js`, `assignments.js`).
- Learner Announcements, Resources, Evaluations & Grades (Mobile): Extended the same empty-state treatment to the remaining pages — when there's nothing to show yet, each now displays a centred icon (reusing that page's own existing accent colour and iconography, e.g. the bar-chart icon already used per-quiz on Grades) with a bold heading and short explanation, instead of a single unstyled line of text. Desktop's existing panel empty states are unchanged; Evaluations keeps its separate "not enrolled in a class" message alongside the new "no evaluations yet" one (`announcements.js`, `resources.js`, `evaluations.js`, `grades.js`, `announcements.css`, `resources.css`, `evaluations.css`, `grades.css`).
- Login Page (Mobile) & Learner Dashboard (Mobile): Splash screen no longer hides on a fixed timer alone before handing off to the dashboard. It now stays visible across the redirect — carrying its remaining time budget via `sessionStorage` — and the dashboard paints an identical splash of its own that only fades out once Home's content has actually finished loading (via a new `iskool:home-ready` event fired from `afterHomeRender()`, or the main content iframe's `load` event) and the original ~1300ms minimum has elapsed, whichever finishes last, with a 6s safety ceiling. This removes the flash of a partially-loaded Home page that could previously appear right after the splash disappeared (`index.php`, `learner_dashboard.php`, `learner_dashboard.css`, `manual.js`).

### Changed
- Login Page (Desktop): The iSkool logo, previously shown next to the school name above the right-hand form panel (`#form-top-brand`), now sits next to the "iSkool" wordmark on the left brand panel instead, at `36px` and with its spin animation removed so it's static; the right panel keeps only the school name badge. Logo-to-wordmark gap tightened to `6px`, the wordmark switched from Fraunces to Nunito (weight `600`), and the whole logo+wordmark block nudged up (`margin-top: -34px`) with no horizontal shift (`index.php`, `index.css`).
- Login Page (Desktop & Mobile): Splash screen "iSkool" wordmark weight reduced from `800` to `600`, matching the cleaner, less-bold weight now used on the left panel's wordmark (`index.css`).
- Login Page (Desktop & Mobile): Splash screen version-footer text weight reduced from `800` to `400`, so it no longer reads as bold against the logo/wordmark above it (`index.css`).
- Learner Home (Mobile): Recent and To-Do card meta lines, and the To-Do empty-state text, recoloured from `#555e6a`/`var(--text-faint)` to `#7d8590` for a clearer secondary-text tier against the card's `#1a1919` background; the shared `≥769px` meta-line override updated to match (`manual.css`).
- Learner Home (Mobile): Class card no longer shows the learner's full name — now shows only the school name and class name (`manual.js`).

### Fixed
- Login Page (Mobile): ENTHROPY splash footer wordmark was sitting at a different vertical position than the visually-identical version on the dashboard's splash handoff screen, despite both using `bottom: 1px`. Cause was structural: the login page anchored a wrapper div (`.branding`) at `bottom: 1px` with the image filling it, while the dashboard anchored the image itself directly. Login page now positions `#splash-brand-wordmark` directly (`position: absolute; bottom` on the image, matching `#dash-splash-brand-wordmark`), with `.branding` reduced to a plain non-positioned wrapper; also removed two now-inert leftover `bottom` values on `.branding` inside the `≤480px`/`≤360px` breakpoints (`index.css`).
- Learner Dashboard (Mobile): Bottom navigation background and header scroll state now recalculate automatically after every learner page renders or changes height, including cached and delayed loads, filtering, accordions, media loading, resizing, and device rotation. This removes the need to scroll before the navigation background reflects the current page length (`learner_dashboard.php`).
- Learner Dashboard (Mobile): Sidebar menu now highlights the active Home, Quiz, Assignments, Resources, Announcements, Evaluations, and Discussions page consistently. Those links were missing the `data-page` values used by the shared active-navigation handler; Grades, Syllabus, and Calendar already had them (`learner_dashboard.php`).
- Learner Dashboard (Mobile): Fixed the header becoming unresponsive after Menu → Calendar → Back. Opening the sidebar disables header clicks via `pointer-events: none`; the Calendar link was closing the sidebar manually instead of through the standard sidebar-close function, so that style was never reset and the header stayed unclickable even though it looked normal. Calendar now closes via the standard sidebar function, and the calendar asset cache version was bumped to `v=2.3` (`assets/js/learner/learner_calendar.js`, `learner_dashboard.php`).
- Teacher Announcements, Assignments, Resources & Evaluations: Email notifications now follow the same logic already used by Quizzes — sending to recipients when push notification delivery fails or is unavailable, and sending both push and email when "Also send email notification" is ticked. Previously only Quizzes reliably emailed; the others did not. Root causes fixed along the way: (1) Announcements, Resources, and Evaluations were calling the push-notification helper before releasing their subscription database statement, interrupting the flow before email fallback could run — reordered to check subscription → close statement → send push → send email fallback, matching Assignments; (2) their forms have separate mobile and desktop email checkboxes, and submission could read the hidden checkbox instead of the one actually ticked, so `force_email` wasn't sent even though push succeeded — forms now explicitly read the visible checkbox (`api/teacher/create_announcement.php`, `api/teacher/create_assignment.php`, `api/teacher/upload_resource.php`, `api/teacher/create_evaluation.php`, `assets/js/teacher/announcements.js`, `assets/js/teacher/evaluations.js`, `assets/js/teacher/resources.js`, `teacher_dashboard.php`).
- Learner Dashboard (Mobile): Fixed tapping Calendar in the menu sometimes showing the previously-open page instead of switching to Calendar. Cause: a slower request from the prior page could finish loading after Calendar was selected and overwrite it, and the mobile Calendar link fell through to the generic sidebar handler instead of having its own. Calendar now owns its mobile tap handling and closes the menu itself; navigation IDs were added so stale responses from Home/Quiz/Assignments/etc. can no longer replace a newly-selected Calendar; Calendar also ignores outdated month-render responses; leaving a Calendar discussion thread now correctly clears its mobile layout and polling state; script versions bumped so mobile/PWA clients receive the update (`learner_dashboard.php`, `assets/js/learner/learner_calendar.js`, `assets/js/learner/assignments.js`, and other learner scripts).
- Learner Dashboard (Mobile): Fixed pull-to-refresh getting stuck on an endless spinner. Traced to a shared failure point with the Calendar navigation issue above: a fragile loader `style.display` monkey-patch in `learner_dashboard.php` that could interfere with both. Removed that monkey-patch; pull-to-refresh now has a 15-second safety timeout, clears stalled prefetch state, and always releases its spinner; the full-page loader no longer shows while pull-to-refresh is active; Calendar updated to respect this refresh state (`learner_dashboard.php`, `assets/js/learner/learner_calendar.js`, `assets/js/learner/announcements.js`, and other learner scripts).

### Removed
- Login Page (Desktop & Mobile): Splash screen no longer displays the app version number (`v1.2.3`); it has been replaced by the ENTHROPY wordmark (`index.php`).
