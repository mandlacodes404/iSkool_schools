## 🎓 Key Features Explained in Detail

Each guide thoroughly covers:

### **Quiz Configuration**
- Duration settings (5-180 minutes)
- Status types (Open, Scheduled, Closed)
- Attempt limits (1 = exam, Unlimited = practice)
- Summative vs Formative
- Weight percentages
- Published marks (when possible/impossible)

### **Layout Modes**
- **Single Page**: All questions visible, can review, can skip
  - Best for: Practice, learning, low-stakes
  - Student stress: Low
  
- **Multi-Page (Linear)**: One question at a time, no going back
  - Best for: Exams, high-stakes, integrity needed
  - Student stress: High but professional

### **Question Types**
1. **MCQ**: Auto-graded, one correct answer, objective
2. **FITB**: Auto-graded, exact answers, vocabulary/facts
   - Free Type: Students type
   - Word Bank: Students choose
   - Scoring: Partial or All-or-Nothing
3. **Open-Ended**: Manual graded, essays/explanations, subjective

### **Advanced Features**
- Shuffle (prevents copying)
- Linear mode (prevents cheating)
- Publish marks (instant feedback)
- Attempt limits (learning control)
- Case sensitivity (spelling control)
