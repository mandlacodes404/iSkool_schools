## BASIC SETTINGS QUICK CHECK

### Duration (Minutes)
- 🎓 Class lecture check: **5-10 min**
- 📖 Unit review: **15-30 min**
- 📝 Chapter test: **45-60 min**
- 🏆 Final exam: **90-180 min**

### Attempt Limit
- **Unlimited** → Students learning, practice (formative)
- **1** → High-stakes exam, final assessment
- **2-3** → Medium importance, allow improvement

### Layout Mode
| Single Page | Multi-Page (Linear) |
|---|---|
| ✅ Practice | ✅ Exams |
| ✅ Learning | ✅ Anti-cheat |
| ✅ Flexible | ✅ Serious |
| ✅ Review before submit | ❌ No going back |

## QUESTION TYPE QUICK DECISION

### MCQ (Multiple Choice)
```
Question text: "What is the capital of France?"
Choices: London, Paris (✓), Berlin, Madrid
Auto-graded: YES ✅
Manual work: NONE
Use for: Facts, recall, objective tests
```

### Fill-in-Blank (FITB)
```
Question text: "Paris is the capital of {blank}"
Answer: France
Sub-type: Free Type OR Word Bank
Auto-graded: YES ✅
Use for: Vocabulary, facts, exact answers
```

### Open-Ended
```
Question text: "Why is Paris important to France?"
Answer: Student types paragraph
Auto-graded: NO ❌ (You grade manually)
Use for: Essays, explanations, deep thinking
```

**⚠️ CRITICAL**: Quiz with open-ended = **Cannot auto-publish marks**

## SUMMATIVE vs FORMATIVE

### Formative (Practice)
- ❌ "Counts toward term mark" unchecked
- Helps learning, builds confidence
- No grade penalty for low scores
- Best: Unlimited attempts

### Summative (Graded)
- ✅ "Counts toward term mark" checked
- Set **Weight %** (e.g., 15%)
- Counts toward final grade
- Best: 1 attempt for integrity

---

## SPECIAL FEATURES

### Shuffle Questions?
- **YES** → Different order per student (prevents copying)
- **NO** → Same order for all (follows lesson sequence)
- **Use YES for**: Classes in same room, high-stakes exams
- **Use NO for**: Homework, online spread-out students

### Publish Marks?
- **YES** → Students see scores immediately ✅ Instant feedback
- **NO** → Scores hidden until you publish manually
- **CAN'T be YES if**: Quiz has open-ended questions

## FILL-IN-BLANK (FITB) SPECIAL OPTIONS

### Sub-Type

**Free Type** (Student types answer):
```
Q: "Paris is in {blank}"
Answer: France
How scored: Matched against accepted list
Good for: Any subject, short answers
```

**Word Bank** (Student chooses from list):
```
Q: "Paris is in {blank}"
Options: [France, Italy, Spain, Germany]
Distractors: Italy, Spain, Germany (wrong but plausible)
Good for: ESL, multiple choice variation, hint support
```

### Scoring Mode (for 2+ blanks)

**Partial**: 50% credit if 1 of 2 blanks correct
- Rewards effort
- Encourages completing question
- Best for: Learning, confidence building

**All-or-Nothing**: 0% credit if even 1 blank wrong
- Requires complete accuracy
- Higher standards
- Best for: High-stakes, mastery-level assessment

## TROUBLESHOOTING

| Problem | Solution |
|---------|----------|
| Can't check "Publish Marks" | Quiz has open-ended questions. Grade those first. |
| Student retook but limit was "1" | Didn't save settings. Did you click Submit/Create? |
| Status says "In Progress" for one student | Student's session interrupted. Have them retake. |
| Students copied all answers | Enable Shuffle next time. |
| Marks show different than I calculated | Check point values per question. FITB may be all-or-nothing. |
| Quiz not appearing to students | Check Status (Scheduled? Start time in future?). |

## POINT VALUE QUICK MATH

**Example: 25 questions, want 100 total points**

Option A: Each worth 4 points (25 × 4 = 100)
Option B: Most worth 4, harder ones worth 5 (flexible)
Option C: 10 worth 3pts + 15 worth 6pts (weighted)

**Best practice**: Make points logical
- Easy questions: 1-2 points
- Medium: 2-3 points
- Hard: 3-4 points

## WHEN TO USE EACH FEATURE

### Use Shuffle? 
✅ **YES** if: Large class, same room, high-stakes, summative
❌ **NO** if: Online homework, small class, formative

### Use Linear Mode?
✅ **YES** if: Exam, high-stakes, 1 attempt
❌ **NO** if: Practice, homework, review

### Use Open-Ended?
✅ **YES** if: You have time to grade, deep thinking needed
❌ **NO** if: You need instant feedback, all objective

### Make it Summative?
✅ **YES** if: Important assessment, counts toward grade
❌ **NO** if: Practice, homework, low-stakes

## FILL-IN-BLANK EXAMPLE

```
Question: "Photosynthesis: 6CO2 + 6H2O → {blank1} + {blank2}O2"

Blank 1:
  Accepted: [C6H12O6, glucose, sugar]
  Case sensitive: NO

Blank 2:
  Accepted: [6]
  Case sensitive: NO

Scoring: Partial (student gets partial credit if 1 blank correct)
or All-or-Nothing (both must be correct)

Student answers: "glucose" + "6"
Result: ✅ Correct answer! Full points.

Student answers: "C6H12O6" + "O2" (used formula instead of number)
Result: Depends on your setup
  - If Partial: 50% points (1 blank right)
  - If All-or-Nothing: 0% points (incorrect spelling of 2nd)
```

## QUICK TIPS

💡 **Pro Tip 1**: Formative (practice) → More attempts, more feedback
💡 **Pro Tip 2**: Summative (graded) → Fewer attempts, stricter format
💡 **Pro Tip 3**: Linear mode prevents cheating but increases stress
💡 **Pro Tip 4**: Open-ended = You work harder grading
💡 **Pro Tip 5**: FITB Word Bank = Good compromise (auto-grade + multiple choice)
💡 **Pro Tip 6**: Always set Weight % if summative (default is 0%)
💡 **Pro Tip 7**: Shuffle OFF for homework, ON for in-class
💡 **Pro Tip 8**: Test your own quiz before releasing to students
