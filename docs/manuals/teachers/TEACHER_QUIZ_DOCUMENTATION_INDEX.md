## 🎁 Bonus Tips

### **Pro Tip 1: Time Management**
- Plan quiz creation with 2-3 days notice
- Don't create day-of (mistakes happen)
- Test your own quiz before releasing

### **Pro Tip 2: Student Communication**
- Always tell students your grading policy upfront
- Explain WHY each option matters
- Example: "Linear mode prevents cheating, so no going back"

### **Pro Tip 3: Continuous Improvement**
- Note which quizzes work well
- Keep templates of successful quizzes
- Reuse and tweak for similar topics
- After each assessment, reflect: What worked?

### **Pro Tip 4: Learning Community**
- Share successful quiz templates with colleagues
- Discuss assessment strategies
- Learn from other teachers' approaches

### **Pro Tip 5: Student Success**
- Formative quizzes help students learn
- Summative quizzes measure learning
- Use both for best results
- Never use quiz to punish (use only to assess)
